วศ.บ. เทคโนโลยีวิศวกรรมแมคคาทรอนิกส์
(ภาษาไทย ปกติ) วิทยาเขตกรุงเทพฯ

เกี่ยวกับฉัน
ผมเป็นนักเรียนระดับมัธยมศึกษาตอนปลายจากโรงเรียนธัญรัตน์ ที่สนใจด้านเทคโนโลยีและการพัฒนาโปรแกรม ชอบเรียนรู้สิ่งใหม่ ๆ และนำความรู้ที่ได้มาสร้างเป็นผลงานและโครงงานต่าง ๆ

เป้าหมายของผมคือ การพัฒนาทักษะและนำความรู้ไปต่อยอดในการศึกษาระดับมหาวิทยาลัย รวมถึงการสร้างนวัตกรรมที่สามารถนำไปใช้ได้จริงและนำมาใช้ในการประกอบอาชีพ
